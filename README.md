#Подробное описание каждого из персонажей -  у каждого из героев игры есть свои интересные и уникальные способности, так же каждый персонаж имеет свой скин, который выдается за разные достижения

1)Паук - быстрый, персонаж имеющий высокую скорость, средний уровень HP

способности - 

1 может выпускать паутину и замедлять врага

2 паучье чутье - предупреждает об атаке врагов за один ход

2) Гарри Поттер - универсальный персонаж, имеющий среднюю скорость, уровень HP и умеющий использовать магия в бою

способности - 

1 Экспеллиармус - отбирает оружие у врага

2 Экспекто Патронус - оглушает всех врагов, забираю у них 50 % HP

3)Я сам - главный герой игры, создавший этот мир

способности - 

1 может копировать способности врагов и использовать их несколько секунд

2 может восстанавливать 50 % здоровья себе после уничтожения 25 противников

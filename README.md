# ОПИСАНИЕ НА АНГЛИЙСКОМ ЯЗЫКЕ(DESCRIPTION IN ENGLISH)

I am a first‑year student at Irnitu, majoring in 09.03.01, group Asub 26‑1. I want to learn how to write my own programs and understand how everything works from the inside. For my first project, I would like to create a game using the Python programming language. I want to make my own game — “Dungeon Run”. My game is a roguelike where the character descends into a dungeon, collects weapons, finds potions that boost their abilities, applies buffs, and fights various bosses.

# CHARACTERS AND SKINS:
The game features several characters, each with their own starting stats. Skins can be obtained for various achievements, and weapons can be obtained by completing a specific task.

# WEAPONS:
There are several types, ranging from melee weapons to ultra‑rare weapons.

# POTIONS:
You can obtain potions for health, teleportation, and invulnerability.

# DUNGEONS AND LEVELS:
Each level has its own bosses, enemies, traps, and chests.

# GAME CONTROL:
wasd - movement

space - attack (use of abilities)

e - inventory

f - interaction

esc - menu

R - return to the main menu

# DETAILED DESCRIPTION OF EACH CHARACTER:
Each of the game’s heroes has their own interesting and unique abilities, and each character also has their own skin, which is awarded for various achievements.

1) 🕸🕷🦸🏻‍♂️ Spider‑Man — a fast character with high speed and average HP level.

abilities:
1 can release webs and slow down the enemy.

2. Spider Sense — warns of enemy attacks one turn in advance.

2) ⚡ Harry Potter — a versatile character with average speed, HP level, and the ability to use magic in combat.

abilities:

1. Expelliarmus — takes the enemy’s weapon.

2. Expecto Patronum — stuns all enemies, taking 50% of their HP.

3) 🙂 I myself — the main character of the game, the one who created this world.

abilities:

1 can copy enemies’ abilities and use them for a few seconds

2 can restore 50% of their own health after defeating 25 enemies

# ENEMIES AND ITEMS AVAILABLE IN THE GAME

Slime — a common enemy, slow

The rat is a fast enemy; it moves 2 cells.

Boss (mutant slug) — appears every 3 levels. When it takes damage, it gets angry and spills a toxic pool.

Potion — restores health (can be carried in the inventory).

Weapon — sword (increases damage), broken warrior’s staff (deals massive damage to the boss but slows the player).
